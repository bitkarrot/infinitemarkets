gallery control: thumbnail tiles for uploaded + pasted entries, button-based
ordering with a Primary badge, per-item remove and Clear all, an Add-by-URL

always sent — fixing the Phase 6 pitfall where a length-guard made
clear-all unreachable.

semantics contract, exercised by the most complex field site.

|----------|-------------|
| pasted URL → thumbnail src | Merchant-supplied remote URL rendered as img src in their own admin; remote host learns viewer IP (disclosed) — never proxied |
| gallery list → PATCH /products/{id} | Ordered image array crosses to the catalog API; `_valid_image_url` re-validates every entry server-side |
