<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| service→Blossom operator | outbound HTTPS to a merchant-configured (but untrusted) endpoint |
| keystore→auth event | merchant signing key used inside custody boundary only |
| DNS→pinned IP | resolution answers could rebind to private space |
| descriptor JSON→stored URL | server-supplied metadata could poison stored references |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-02-01 | Tampering | endpoint host / DNS | critical | mitigate | request-time `resolve_and_check_egress` rejects any non-public answer; connect to pinned IP with TLS SNI; config-time `validate_blossom_url` never trusted as egress control |
| T-06-02-02 | Spoofing | BUD-11 token | high | mitigate | 300s expiration (D-09), `x`+`server` scoping, one event signed per upload, token never logged/persisted/returned |
| T-06-02-03 | InfoDisclosure | 3xx redirect | high | mitigate | ALL 3xx rejected on PUT — body and Authorization never forwarded to a second host |
| T-06-02-04 | Tampering | descriptor | high | mitigate | strict validation: sha256/size/type/https same-host url ≤2048 before the URL is exposed (D-11) |
| T-06-02-05 | DoS | blocking transport / slow server | medium | mitigate | asyncio.to_thread + asyncio.wait_for deadline + per-merchant Semaphore(4) (D-13); bounded descriptor read |
| T-06-02-06 | Tampering | server-order persistence | medium | mitigate | order-preserving dedup restores "first = primary"; documented costly contract change |
| T-06-02-07 | InfoDisclosure | key custody | critical | mitigate | signing stays inside `MerchantKeyStore.sign_event`; nsec loaded+released in the keystore; result dict carries descriptor fields only |
| T-06-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | no installs — RESEARCH.md Package Legitimacy Audit has no inputs (stdlib + pinned nostr-sdk only) |
</threat_model>
