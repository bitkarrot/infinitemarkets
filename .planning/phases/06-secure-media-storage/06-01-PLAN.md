<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser→POST /media/upload | untrusted multipart bytes + filenames cross into authenticated route |
| route→filesystem | verified bytes written to host data folder outside the package |
| route→DB | merchant-scoped reads for referenced-set computation |
| DELETE path param→filesystem | `{name}` could attempt traversal |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01-01 | Tampering | file content | high | mitigate | magic-byte `_sniff` allowlist png/jpg/webp only; SVG/GIF/polyglot rejected regardless of filename or Content-Type |
| T-06-01-02 | DoS | request body / storage | high | mitigate | bounded stream `16*(25MB+8KB)`, per-file cap, 16-file cap, 400MB quota counting all namespace bytes incl. leftovers (D-01) |
| T-06-01-03 | InfoDisclosure | merchant namespace | medium | mitigate | HMAC privacy-key-derived 24-char opaque namespace; path unguessable; never equals merchant id |
| T-06-01-04 | Tampering | DELETE /media/unused/{name} | high | mitigate | strict `[0-9a-f]{64}\.(png|jpg|webp)` fullmatch before any filesystem touch — separators impossible |
| T-06-01-05 | Spoofing | route auth | high | mitigate | `check_user_exists` + `_mid` merchant scope + `problem_boundary` Origin/CSRF (cookie mutations) |
| T-06-01-06 | Tampering | profile-bound URL | medium | mitigate | D-05/D-08 gate blocks uploads that would emit an unreachable origin for Nostr fields |
| T-06-01-07 | Tampering | tmp/partial writes | medium | mitigate | write-to-`tmp` + re-hash + atomic `replace`; same-size dedup makes retries safe |
| T-06-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | no installs this phase — RESEARCH.md Package Legitimacy Audit has no inputs |
</threat_model>
