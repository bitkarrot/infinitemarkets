## Phase Goal

**As a** merchant moving to Infinite Markets, **I want** to upload my old
catalog (nostrmarket export, NIP-15 event dump, or Shopify CSV), preview and
dry-run it before anything lands, and get an auditable signed record of what
came in and what stock is still owed to unpaid legacy orders — **so that** my
migration is reviewable, reversible, and never touches the network or my
keys.

(Story source: LEG-03 + CONTEXT D-01..D-06.)

</objective>

### Task 1: m00N_migration schema + models

`catalog_imports`: id, merchant_id, source_format, filename, byte_size,
state (uploaded|previewed|validated|dry_run|executed), counts
(rows_total/valid/skipped/errors), manifest_json, manifest_sig,
created_at/executed_at. `import_rows`: id, import_id FK CASCADE, row_index,
legacy_id, payload_json, status (pending|valid|invalid|skipped|imported|
updated), error, product_id. `csv_presets`: id, merchant_id, name,
mapping_json, created_at (+ unique merchant+name). `imported_liabilities`:
id, merchant_id, import_id, legacy_order_ref, legacy_product_id, qty,
invoice_ref, payable_until, state (open|resolved|partitioned|cancelled),
resolution, resolved_at. Products: `legacy_source TEXT`, `legacy_id TEXT`,
`import_id TEXT` + unique index (merchant_id, legacy_id) partial on non-null.
Models for all. Append to explicit migration list.

### Task 2: migration_import.py — parsers, validation, execute

- `detect_and_parse(file_bytes, filename)` → row dicts: NDJSON/JSON-array
  detector (kind 30017→stall meta; kind 30018→product row; others skipped),
  nostrmarket JSON `{stalls[],products[],zones[]}` → products with stall/zone
  names into metadata note, CSV via `csv.DictReader` + preset column map.
- `validate_rows` — name non-empty, price numeric ≥0, qty int ≥0, images
  stored as external URLs (never fetched); row-level errors recorded, never
  abort batch.
- `dry_run(import_id)` → diff report: would_create/would_update/would_skip/
  would_error counts + per-row actions — no writes.
- `execute(import_id)` → DomainTransaction: upsert drafts through the catalog
  create/validate DTO path keyed on (merchant, legacy_id); write
  import_rows results; write imported_liabilities from the optional
  `liabilities` upload section; build canonical manifest JSON + Schnorr sign
  with merchant key; mark executed.
- CSV preset CRUD + built-in Shopify mapping constant.

### Task 3: Wizard API + Migration admin UI

Endpoints under existing merchant auth: `POST
/merchants/{id}/imports` (multipart file + optional format hint +
optional liabilities JSON section), `POST /imports/{id}/preview` (parse +
row table), `/validate`, `/dry-run`, `/execute`, `GET /imports/{id}/audit`
(manifest + counts + row statuses), `GET /merchants/{id}/liabilities`,
csv_presets GET/POST/DELETE. New `admin_migration.js` module: Migration nav
section — wizard stepper (upload → preview grid → validation errors →
dry-run diff → execute → audit receipt w/ manifest hash + sig), plus
liabilities panel (list, qty sums). Register in admin.html nav.

### Task 4: test_migration_import.py

Fixture NIP-15 dump (2 stalls, 4 products, 1 kind-5 ignored, 1 inactive),
nostrmarket JSON export, Shopify CSV (+ a saved custom preset). Cover:
format detection, row validation errors non-fatal, dry-run writes nothing,
execute lands drafts only (no outbox rows), re-import dedups via legacy_id,
manifest signed + verifies against merchant pubkey, liabilities written,
upload size bound, cross-merchant access denied.
