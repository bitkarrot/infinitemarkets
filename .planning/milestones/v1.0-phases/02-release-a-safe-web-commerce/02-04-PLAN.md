## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public JS -> public API | token stays in memory/header; fragment never reaches the server |
| admin JS -> admin API | owner-scoped + origin/CSRF guard; legal actions only rendered |
| theme editor -> token store | client preview uses the same contrast math; server gates authoritative |
| rendered surfaces -> observers | no secrets/tokens/internal ids in HTML/JSON — scanned in tests |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-204-01 | Information disclosure | token leaking via fragment/history/referrer | critical | mitigate | replaceState strip + in-memory only + no-referrer + tests asserting absence |
| T-204-02 | Tampering | UI offering illegal transitions | high | mitigate | legal-action map renders only contract-legal controls; API rejects regardless (02-03) |
| T-204-03 | Information disclosure | admin render leaking secrets | high | mitigate | response scans over seeded fixtures; technical-details pane shows truncated evidence only |
| T-204-04 | Elevation | theme tokens styling admin | medium | mitigate | `.gm-public` scoping asserted; admin never receives token object |
| T-204-05 | Denial of service | buyer confusion into double payment | critical | mitigate | creation_unknown copy forbids second invoice; no pay-again affordance; settlement copy only after LNbits confirm |
